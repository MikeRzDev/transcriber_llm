# 02 — C ABI: `transcribe-ffi`

The foundation for Go ([05-go](05-go.md)), Java ([06-java](06-java.md)), and any other
FFI consumer. Python and Node do **not** go through this layer — they bind the Rust core
directly ([03-python](03-python.md), [04-node](04-node.md)).

## Crate & artifacts

- Crate `crates/transcribe-ffi`, `[lib] name = "tstt"`,
  `crate-type = ["cdylib", "staticlib"]` → `libtstt.dylib` / `libtstt.so` / `tstt.dll`.
- Header `include/tstt.h` generated by **cbindgen** (`language = C`, `cpp_compat = true`,
  include guard `TSTT_H`), **committed** to the repo and CI-diffed so consumers can vendor
  it and drift is impossible.
- `tstt.pc.in` pkg-config template; release tarballs contain `lib + tstt.h + tstt.pc`
  per platform ([08-ci-release](08-ci-release.md)).
- `tests/smoke.c` — compiled and run against the built cdylib in CI (loads tiny model,
  transcribes a fixture, checks a segment arrives via callback).

## Design decision: UTF-8 JSON strings for requests, results, and events

All structured data crosses the ABI as UTF-8 JSON `char*`, not C structs. Rationale:

1. The core `Event` enum has **16 variants** with heterogeneous payloads, and segments are
   variable-length arrays with optional fields. A struct ABI would need ~12 public structs
   plus tagged unions, and every added field would be an ABI break. JSON collapses this to
   one `const char*` and makes additive evolution free (`tstt_abi_version` never bumps for
   a new JSON field).
2. Every consumer language parses JSON natively. Event rate is tens/sec against seconds of
   GPU compute — serialization cost is noise.
3. One cross-language contract, tested against `schemas/*.json` golden files, so bindings
   cannot drift.

Granular structs are only warranted for hot-path per-sample APIs, which this is not.

## Function surface (17 functions)

```c
/* ---- meta ---- */
const char* tstt_version(void);        /* semver string; static storage, never freed */
int32_t     tstt_abi_version(void);    /* bumped ONLY on ABI breaks; check at load */
char*       tstt_capabilities(void);   /* {"metal":bool,"cuda":bool,"mlx_supported":bool,
                                          "mlx_runtime_ready":bool,"ffmpeg":bool} */

/* ---- errors & memory ---- */
const char* tstt_last_error(void);     /* thread-local: last failure on THIS thread,
                                          JSON {"code":"...","message":"..."}; lib-owned */
void        tstt_string_free(char* s); /* frees every non-const char* the lib returns */

/* ---- engine lifecycle ---- */
typedef struct tstt_engine tstt_engine;              /* opaque */
tstt_engine* tstt_engine_new(const char* config_json);
             /* config: {"models_dir":path?, "mlx":"auto"|"off"|"require", "threads":n?}
                NULL on error (see tstt_last_error) */
void         tstt_engine_unload(tstt_engine*);       /* drop resident model, keep engine */
void         tstt_engine_free(tstt_engine*);         /* joins worker, drops whisper ctx.
                                                        MANDATORY before process exit
                                                        (ggml atexit hazard) */

/* ---- cancellation ---- */
typedef struct tstt_cancel tstt_cancel;              /* opaque; thread-safe */
tstt_cancel* tstt_cancel_new(void);
void         tstt_cancel_request(tstt_cancel*);      /* callable from ANY thread */
void         tstt_cancel_free(tstt_cancel*);

/* ---- events ---- */
/* Invoked on the WORKER thread. event_json is valid only for the duration of
   the call — copy it if you keep it. Return false to request cancellation.
   Do NOT call tstt_engine_* / tstt_transcribe / tstt_hub_* from inside the
   callback (deadlock: the engine mutex is held); tstt_cancel_request IS safe. */
typedef bool (*tstt_event_cb)(const char* event_json, void* user_data);

/* ---- work (all blocking) ---- */
char* tstt_transcribe(tstt_engine*, const char* request_json,
                      tstt_cancel* cancel_or_null,
                      tstt_event_cb cb_or_null, void* user_data);
      /* request: {"audio":path, "model":path?, "language":"en"?, "diarize":bool?,
                   "split":"auto"|...?}   (model omitted = engine default resolution)
         returns TranscriptionResult JSON, or NULL (see tstt_last_error) */

char* tstt_models_list(tstt_engine*, const char* models_dir_or_null);
      /* returns {"models":[{"path","name","size_bytes","is_dir"},...]} */

char* tstt_hub_search(const char* query, tstt_cancel*);
char* tstt_hub_list_files(const char* repo, tstt_cancel*);
char* tstt_hub_download(const char* request_json, tstt_cancel*,
                        tstt_event_cb cb_or_null, void* user_data);
      /* request: {"repo","file"?, "subdir"?, "dest_dir"}
         progress events: {"type":"download_progress","got":u64,"total":u64}
         returns {"path": "..."} */

char* tstt_export_render(const char* doc_json, const char* format);
      /* format: "llm.md" | "json" | "txt" | "srt";
         doc: TranscriptDoc mirror {"segments":[...], "source_name", "duration_secs",
              "language"?, "model_name"} */
```

## Semantics

### Ownership

- Input strings are borrowed UTF-8, copied before return — caller may free immediately.
- **Every returned `char*` except `tstt_version` and `tstt_last_error` is caller-owned**
  and must be released with `tstt_string_free`. Handles are released only by their own
  `_free` function. All `_free` functions accept NULL as a no-op.

### Errors

- Pointer-returning functions signal failure by returning NULL; detail via
  `tstt_last_error()` → JSON `{"code": "...", "message": "..."}` using the stable codes
  from [01-core-api](01-core-api.md#typed-errors-srcerrorrs): `model_not_found`,
  `audio_decode`, `engine`, `cancelled`, `mlx_runtime_missing`, `unsupported_platform`,
  `network`, `io`, `invalid_arg` — plus the FFI-only code **`panic`**.
- The error slot is **thread-local** — safe for concurrent callers.
- A cancelled transcription is an *error return* with code `cancelled`. **Terminal
  outcomes (done / cancelled / error) are return values, never callback events** — the
  callback only ever sees non-terminal events. This gives every binding a single
  completion path.

### Events

Event JSON is the core's serde encoding verbatim (internally tagged, snake_case —
[01-core-api](01-core-api.md#serde--api-stability)). Examples:

```json
{"type":"loading_model","name":"ggml-base.en.bin"}
{"type":"load_progress","pct":80}
{"type":"model_ready","load_secs":1.2}
{"type":"decode_progress","pct":-1}
{"type":"progress","pct":42}
{"type":"segment","start_ms":0,"end_ms":1500,"text":" Hello.","speaker":null}
{"type":"segments_final","segments":[...]}
{"type":"engine_log","line":"..."}
{"type":"engine_heartbeat","secs":12}
{"type":"download_progress","got":1048576,"total":147951465}
```

Negative `pct` = indeterminate (spinner), matching today's TUI semantics.

### Threading

- One engine **serializes jobs** behind an internal mutex; concurrent `tstt_transcribe`
  calls on the same engine block in order.
- **Multiple engines per process are supported** — each owns its worker thread and model
  memory (document the cost of N resident models).
- `whisper_rs::install_logging_hooks()` is process-global: called exactly once behind
  `std::sync::Once` (core guarantees this — [01-core-api](01-core-api.md#lifecycle-contract)).
- Callbacks run on the worker thread; consumers must marshal to their own threads if
  needed (each binding spec covers its mechanism).

### Panic safety

Every `extern "C"` function body is wrapped in `std::panic::catch_unwind`; a panic maps to
NULL + error code `panic`. The ffi crate must NOT set `panic = "abort"`. Unwinding never
crosses the FFI boundary.

### Symbols

The cdylib statically links whisper.cpp/ggml. Those symbols must not leak — a host process
may load another whisper build (e.g. Python `pywhispercpp`) and collide. Export **only**
`tstt_*`:

- Linux: linker version script (`-Wl,--version-script=tstt.map`),
- macOS: `-exported_symbols_list`,
- Windows: default `dllexport`-only.

CI enforces with an `nm`-based check (no exported non-`tstt_*` dynamic symbols —
[08-ci-release](08-ci-release.md)).

### Lifecycle

`tstt_engine_free` is **mandatory before process exit** — it joins the worker and drops the
whisper context so ggml's atexit destructors have nothing live to trip over (risk #1,
[00-overview](00-overview.md#consolidated-risk-register)). The header documents this
loudly. The library itself never installs exit handlers and never `_exit`s.
