# 05 — Go binding: `bindings/go`

**cgo over the C ABI** ([02-c-abi](02-c-abi.md)). Not a cargo workspace member — own
`go.mod`: module `github.com/<owner>/transcriber_llm/bindings/go`, package **`tstt`**.
Ships in **P2**.

## Native library distribution (the hard problem)

`go get` cannot run cmake, so `libtstt` must pre-exist on the build machine. Decision:

- **Primary: system-installed lib + pkg-config** — `#cgo pkg-config: tstt`. This is the
  established cgo pattern (libvips/libsqlite style). The release tarball ships `tstt.pc`;
  P2 adds a Homebrew formula for `libtstt`.
- **Convenience: `make fetch-lib`** in `bindings/go/` — downloads the versioned release
  tarball into `~/.cache/tstt/<version>/` and prints the `PKG_CONFIG_PATH` /
  `LD_LIBRARY_PATH` (/ `DYLD_LIBRARY_PATH`) exports. Used by CI and quick starts.
- **Rejected: vendoring prebuilt `.a` per platform in the module** — tens of MB per
  platform in module downloads, and static linking drags platform-specific link lines
  (Metal/Foundation frameworks on macOS, the C++ runtime everywhere) into consumer builds
  that plain `#cgo LDFLAGS` cannot express portably.

The package verifies `tstt_abi_version()` at init and returns a clear error on mismatch.

## API

```go
eng, err := tstt.NewEngine(tstt.Config{ModelsDir: "...", Mlx: tstt.MlxAuto})
defer eng.Close()          // REQUIRED (ggml hazard); runtime.AddCleanup as best-effort backstop

res, err := eng.Transcribe(ctx, "audio.m4a",
    tstt.Options{Model: "...", Language: "en", Diarize: true},
    func(ev tstt.Event) bool {   // nil allowed; return false = cancel
        // ev.Type switch: EventSegment, EventProgress, ...
        return true
    })
// res: Segments []Segment, Language string, DurationSecs, ElapsedSecs float64

models, err := tstt.ListModels(dir)
hits, err   := tstt.SearchHub(ctx, query)
path, err   := tstt.DownloadModel(ctx, tstt.DownloadRequest{Repo, File, Dest}, onProgress)
srt, err    := tstt.RenderExport(doc, tstt.FormatSRT)
```

- Events/results unmarshal from the ABI's JSON into Go structs generated to match
  `schemas/` (golden-file tested).
- Errors: `*tstt.Error` with `Code` (stable wire code) and `Message`; `errors.Is`
  helpers for `tstt.ErrCancelled`, `tstt.ErrModelNotFound`, etc.

## Callback & cancellation plumbing

- One exported bridge function (`//export tsttGoEventBridge`) is registered as the C
  callback for all calls; `user_data` carries a `cgo.Handle` referencing the per-call Go
  closure. The handle is deleted when the call returns.
- `Transcribe(ctx, ...)` starts a goroutine watching `ctx.Done()` that calls
  `tstt_cancel_request` on the call's cancel handle; cancellation surfaces as
  `ErrCancelled` (wrapping `ctx.Err()`).
- Callback threading follows the ABI contract: invoked on the worker thread; the closure
  must not call engine methods (documented; `cancel` via context is the supported path).

## Tests

`go test` in CI downloads the ffi artifact (fetch-lib path), sets `PKG_CONFIG_PATH`, and
runs: transcribe fixture with tiny model, context cancellation, error-code mapping,
golden-file JSON check.
